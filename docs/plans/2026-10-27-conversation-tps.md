# 当前对话 TPS：可行性分析与实施计划

> 显示位置与设置已按后续反馈修订，当前行为以[修订验证记录](../reviews/2026-10-27-tps-display-revision.md)为准。以下保留初次设计与验证历史。

日期：2026-10-27。状态：已实施并通过本机核心及界面自检，结果与未完成的验收项目见[验证记录](../reviews/2026-10-27-conversation-tps.md)。下文保留初次设计依据；实际定位边界以用户后续确认及验证记录为准。

## 已确认需求与建议默认值

用户要求在 CodexTouchBar 集成当前对话 TPS（每秒输出 token 数），菜单栏和 Codex 输入框均支持显示，且各自可独立关闭。

建议在「设置 → 通用 → 会话速度」提供两个即时生效、独立持久化的开关：

- 在菜单栏显示 TPS。
- 在 Codex 输入框旁显示 TPS。

两个开关默认关闭，升级后保留现有体验。四种组合均支持；任意一个开启才启动共享数据源，两者均关闭时释放读取、连接、监听与浮层资源。无 Touch Bar 的 Apple Silicon Mac 同样可用。

本次范围为 TPS。参考截图中的累计 token、缓存命中率、上下文比例不自动加入本次产品范围。额度读取、两张额度卡、历史、提醒、四个 Touch Bar 按钮及 Control Strip 沿用现有行为。

## 1. 已核实的事实

### 参考项目与指标口径

参考对话指定的项目是 Windows 的 [dongyue-19/codex-statusbar](https://github.com/dongyue-19/codex-statusbar)，本次阅读时 main 指向 `17f0ddd25512b9a823b56a37da325d36ca53971f`，许可证为 MIT。读取的是源码与文档，没有运行该项目的程序或测量脚本。

它使用独立透明窗口贴靠 Codex，通过本地 IPC（进程间通信）识别所跟随的对话，再增量读取该对话的 session JSONL。值得借鉴的是数据读取、计时与状态表达；Windows 窗口定位不能直接移植为 AppKit 实现。

它的 TPS 分母是 `Reasoning` 与 `AgentMessage` 输出时间区间的**并集长度**，不是整轮墙钟耗时；工具执行、审批和用户等待不计入分母。输出 token 包含推理 token，不能再把推理 token 加一遍。项目也明确说明：数据通常在一次模型响应完成后更新，不是逐 token 的瞬时速度。

源码依据：[指标和限制](https://github.com/dongyue-19/codex-statusbar/blob/17f0ddd25512b9a823b56a37da325d36ca53971f/README.md)、[TpsTracker.cs](https://github.com/dongyue-19/codex-statusbar/blob/17f0ddd25512b9a823b56a37da325d36ca53971f/src/CodexStatusbar/TpsTracker.cs)、[RolloutReader.cs](https://github.com/dongyue-19/codex-statusbar/blob/17f0ddd25512b9a823b56a37da325d36ca53971f/src/CodexStatusbar/RolloutReader.cs)。该项目报告的准确率与性能不视为本项目的验证结果。

### 当前 CodexTouchBar 的接入点

- `CodexClient.swift` 为每次额度刷新启动短生命周期 `app-server --stdio`，读取 `account/rateLimits/read`。这个额度接口不能直接提供当前对话 TPS。
- `UsageStore.swift` 是当前 UI 状态入口，并维护仅含显示字段的额度缓存。会话速度应进入独立的内存状态，再由这一 UI 状态入口统一发布；不混入持久化的 `UsageSnapshot`、额度历史或额度刷新规则。
- `Preferences.swift` 已有偏好与变更通知模式，适合增加独立的 TPS 显示选项。
- `SettingsWindowController.swift` 的通用页使用固定高度容器；新增内容必须检查是否溢出，必要时只给通用页增加原生滚动容器。
- `UsageIcon.swift` 的菜单栏宽度固定；新增 TPS 必须显式管理启用后的宽度，关闭后恢复原尺寸。
- `DesktopActions.swift` 已有辅助功能权限检查和授权入口，可复用权限体验；现有实现只扫描菜单，尚无输入框定位器。

### 本机只读验证结果

本次检查了当天少量日志的结构与计数字段，未输出或保存聊天正文、代码、工具结果或原始消息。

1. 本机日志包含 `token_usage_record`、`event_msg/token_count`，以及 `event_msg/item_completed`。
2. `started_at_ms`、`completed_at_ms` 位于 `item_completed.payload`，其 `item.type` 能区分模型输出和工具。检查到的模型输出事件具有有效时间区间；一个已完成轮次也同时具有输出用量与有效模型时间。
3. 检查到的日志版本为 `0.164.0-alpha.11.1`。同时存在 `Codex Desktop` 与 `codex_work_desktop` 来源，另有子代理来源，不能只按一个 originator 字符串筛选。
4. 样本中 `turn_token_usage` 与 `thread_token_usage` 相同，不能仅凭字段名称把前者当作本轮用量。
5. 已安装客户端代码包含 macOS 的本地 socket 路径、长度前缀 JSON 协议和 `thread-stream-following-changed` 事件。
6. 对当前用户拥有的 `~/.codex/ipc/ipc.sock` 进行短时连接，仅发送 `initialize`，成功收到带 `conversationId`、`hostId`、`following`、`sourceClientId` 的跟随事件。
7. 以只读方式查本机 `state_5.sqlite`，该对话 ID 能映射到 sessions 目录内的现存日志，且日志头部 ID 一致。

探测只输出字段结构与匹配布尔值，未保存原始 IPC/session 数据；没有发模型请求、读取凭据、修改会话或修改已安装客户端。

验证边界：以上证明当前单个会话的数据链路可通，尚未验证切换多个空闲对话、多个窗口的焦点对应关系、输入框辅助功能结构、浮层位置、跨版本兼容和实际显示效果。

官方 [App Server 文档](https://learn.chatgpt.com/docs/app-server)确有 `thread/tokenUsage/updated` 等事件，但这不代表新启动的额度查询进程可以订阅桌面现有 stdio 连接，也没有由此得到官方的「当前窗口所选对话」接口。方案因此不依赖额外启动常驻 app-server 或恢复用户对话。

## 2. 可行性判断与技术方案

结论：**菜单栏方案可行性高；输入框浮层可行，但要先验证定位与窗口对应关系；TPS 的更新粒度受 Codex 日志限制。**

```text
Codex 本地 IPC：当前跟随的对话与主机
                   ↓
只读索引：对话 ID → 对应 rollout 路径
                   ↓
有界 JSONL 尾读、文件变更监听、增量解析
                   ↓
按对话/轮次整理输出用量与模型输出时间
                   ↓
独立的会话速度状态 → UsageStore 统一发布 UI 状态
                   ├─ 菜单栏 TPS（开关 A）
                   └─ 输入框透明浮层（开关 B + 定位权限）
```

TPS 采用「当前对话当前轮次的模型输出平均吞吐率」：

```text
TPS = 本轮已确认的官方 output_tokens
      ÷ 本轮已确认的 Reasoning/AgentMessage 时间区间并集秒数
```

这是一项由本地运行记录推导的指标，不宣称是服务器逐 token 的精确解码速度。分子、分母必须对应同一轮次与同一观测进度。

### 用量、计时和生命周期

- 累计用量采取最新快照替换，绝不对两种 carrier 重复求和。优先使用完整轮次的累计差值，并用 `response_id` 去重后的响应用量交叉检查。
- 旧格式没有响应 ID 时，基于累计快照变化判断新增用量；不能只靠「用量数值相同」合并两次不同响应。计数回退、来源冲突、轮次基线缺失时暂不显示 TPS。
- 用量可能晚于完成事件到达，状态机要允许同一轮次迟到补全，防止计入下一轮。重复完成记录按 item ID 去重；重叠时间段合并，不能简单累加。
- 分母只含已确认模型输出区间，不用 `整轮耗时 - 首 token 延迟` 代替。推理 token 是 output 的子集，不重复计入。
- 开始新轮次立刻进入等待状态，不沿用上一轮数值；工具执行时保留已有测量并注明「上次测量」；完成后保留本轮最终值。
- 切换对话先清空当前显示，再读取对应状态。索引无匹配、远端主机日志不可达、纯云端对话无本地数据、临时对话未落盘时显示不可用，不展示其他对话数据。
- 短于建议阈值（初始 0.5 秒，待实测）的样本标为不足；无效时长、负数、非有限值、异常计数不生成数字。首版优先保留可核对的原始平均值，不预先增加跨样本平滑。

### 有界读取与隐私

- 尊重实际 Codex 数据目录；默认 `~/.codex`，可识别可验证的 `CODEX_HOME`，不混用不同数据目录的 IPC、索引和日志。GUI 启动的环境变量不完整时给出不可用原因。
- 本地 IPC 仅做初始化和被动接收；不发送开始、恢复、中断、修改对话等指令。只消费对话路由字段，其余载荷尽早丢弃，不记录原始帧。
- 校验 socket/父目录的用户归属与访问权限；索引仅以只读 SQLite 打开、参数化查询 ID/rollout 路径，正确读取 WAL，不把数据库视为静态文件。
- 路径须解析并确认位于选定数据目录的受支持 session 根目录，日志头部 ID 与所选对话一致；检查文件替换、截断、归档、符号链接和读取时竞态。
- 初次读取建议从末尾 4 MiB 开始，设明确总读取上限。缺少完整轮次或基线则显示不足，不能无限扩展到整段历史；后续只读追加字节。
- 使用文件事件并合并突发更新；保留未完成行，限制单行与单次处理量，超大工具结果按行跳过。解析只保留 ID、类型、计数、时间，不保存正文。
- 文件字节不可避免会短暂进入内存；应明确这是只读本地日志访问，不能宣称完全不接触正文所在文件。TPS 状态和会话 ID 仅留内存，首版不新增持久化会话缓存。
- 断连采用有界退避；关闭两个显示开关、应用退出、Codex 退出及睡眠时释放相应资源，唤醒后重新校验。慢任务结果带会话/生命周期版本标识，防止关闭后或切换后回写。

## 3. 两个显示位置的行为

### 设置与菜单栏

在通用页新增「会话速度」分组，说明「根据本机 Codex 运行记录计算，在模型响应完成后更新」。复用原有控件、字体和间距，放置两个独立复选框；只有输入框选项需要辅助功能权限状态与授权入口。

菜单栏在现有两行额度读数旁增加紧凑的 `⚡ 243 t/s` 区域，使用与现有菜单栏相配的单色图标和等宽数字。TPS 不使用额度四档风险色。宽度根据启用状态与统一测量规则管理，避免逐位抖动或截断；关闭时恢复原有宽度。额度 popover 可在现有详情区域给出已开启 TPS 的状态与统计口径，沿用原生透明材质，不重排两卡或更换外观。

菜单栏单独启用时不申请辅助功能权限。Codex 不在前台时如保留最近查看的结果，提示必须说明其归属为「最近查看的对话」；Codex 退出后转为不可用，不继续称为实时数据。

### 输入框附近的浮层

拟使用 AppKit 的透明、非激活 `NSPanel`，贴靠 Codex composer 区域。浮层穿透鼠标、不能成为键盘焦点；不改 Codex 文件或 DOM，不注入进程。

先通过辅助功能（AX）读取前台 Codex 窗口与输入区域的角色、标识和边界，验证是否能定位 composer 工具栏。优先使用已有空白区域；宽度不足时缩短为 `243 t/s`，仍无法安全放置则隐藏。不得覆盖输入文字、模型选择、上下文指示、麦克风、发送按钮等操作区域；不使用固定屏幕坐标作为常态定位方案。

只在用户开启该项且权限已具备时创建定位器；未授权时保留用户选择、显示待授权原因，另提供明确的「授权辅助功能」按钮，避免启动时主动弹窗。菜单栏开关不受影响。定位只读取必要的结构和尺寸，不取输入内容，不模拟键鼠，也不依赖屏幕截图或录屏权限。

采用窗口/布局事件监听与有界重定位，避免高频遍历整个辅助功能树。应用切后台、目标窗口最小化/关闭、进入首页或设置、输入框不存在、权限撤回、窗口对应关系不明时隐藏。覆盖调整窗口大小、侧栏与底部面板展开、输入框高度变化、多显示器缩放及全屏/Spaces 的定位验证。

多窗口必须单独设能力门槛：IPC 的 `sourceClientId` 能区分发送方，但当前尚未证明它能可靠映射到 macOS 焦点窗口。实施时验证映射；若不能确认，检测到歧义就隐藏浮层、菜单栏显示原因。不能把「最近切换的窗口」冒充「当前焦点窗口」。

### 显示状态约定

| 场景 | TPS 表达 |
| --- | --- |
| 新对话或新一轮尚无可用样本 | `— t/s`，详情说明等待输出 |
| 已有本轮有效样本，随后继续生成 | 最新的本轮累计测量值，注明更新粒度 |
| 模型转去调用工具或数值尚未更新 | 保留值，详情注明「上次测量」 |
| 本轮完成 | 保留最终值，详情注明「上一轮」 |
| 样本太短或恢复时只读到半轮 | `— t/s`，说明样本不足 |
| 当前对话不明、远端日志缺失或格式不支持 | `— t/s`，详情给出原因，输入框浮层隐藏 |
| 关闭一个位置 | 该位置立即撤下，另一位置继续 |
| 两个位置均关闭 | 无 TPS 显示、连接、文件读取或定位任务 |

## 4. 风险与处理

| 风险 | 判断 | 处理 |
| --- | --- | --- |
| 账号与请求行为 | 方案本身不新增模型请求或使用认证凭据；不能承诺平台未来政策 | 严格限定本地观察；没有直接服务端 HTTP、OAuth、代理或请求改写 |
| 内部协议兼容 | 主要维护风险；IPC、SQLite、JSONL 都可能变化 | 封装版本适配，未知字段安全跳过，失效显示原因，保持额度功能正常 |
| 当前对话识别 | 单会话连接与日志映射已验证，切换和多窗口尚未验证 | 先通过路由验收；无可靠 ID 时不以 mtime/最近活动静默猜测 |
| TPS 精度与实时性 | 不能提供逐 token 瞬时值；短样本和事件顺序可导致异常 | 明确口径、并集计时、去重、完整性检查和等待/保持/完成状态 |
| 日志隐私 | session 可能包含聊天、代码和工具结果 | 最小字段解析，只留内存，不复制真实日志到 fixtures 或报告 |
| 输入框定位与遮挡 | 浮层比菜单栏复杂，AX 树和布局随版本变化 | 权限按需、事件定位、点击穿透、安全空间不足即隐藏 |
| 后台消耗 | 大日志、重连和 AX 扫描可能增加资源使用 | 有界尾读与追加解析，事件合并，UI 更新节流，关闭即释放 |
| 功能相互影响 | TPS 失败不应影响额度、设置或无 Touch Bar 模式 | 独立服务与状态，主线程只更新 UI，数据错误局部降级 |

## 5. 实施步骤与阶段验收

1. **能力原型与冻结口径。** 在当前签名应用身份下验证空闲对话切换、前后台、退出重启，以及 AX composer 定位；检验多窗口映射。确定单窗口支持边界、不可用行为和两种显示的布局。已完成的 socket/日志映射探测不能替代这一阶段。
2. **纯解析与 TPS 计算。** 编写最小字段模型、增量 JSONL reader、区间合并和轮次状态机；用手工合成数据验证已知答案，覆盖双 carrier、响应去重、迟到记录、计数重置和中途恢复。
3. **只读会话观察服务。** 接入本地 IPC、只读日志路径索引、文件事件、断线重连与生命周期清理；过滤 CLI/子代理混入，按 `(hostId, conversationId)` 隔离状态，保留有限的内存缓存。
4. **状态与两个设置开关。** 引入独立偏好，`UsageStore` 统一发布额度与会话速度 UI 状态；`AppDelegate` 按两个开关的逻辑或管理数据源。验证四种组合、立即关闭、重启恢复、菜单栏无需 AX 权限。
5. **菜单栏与输入框显示。** 完成菜单栏宽度和状态提示、可选详情行，再实现带权限状态的 AX 定位和 NSPanel。两处订阅同一快照，保证对话和数值一致。
6. **回归、资源与视觉验收。** 运行构建、真实可执行自检及隔离 UI 检查；检查完整原生 popover（含箭头），测量关闭、闲置和生成时的资源使用。记录当前系统版本、客户端版本、已验项目和剩余限制，更新用户与开发文档。

建议新增模块按职责拆分为 `SessionTPSModels`、`SessionTPSCalculator`、`SessionRolloutReader`、`CodexSessionObserver`、`SessionTPSService`、`ComposerAnchorTracker`、`ComposerTPSPanelController`。实际文件数量按实现复杂度调整；诊断与 fixtures 单独存放，不放进领域逻辑。

改动现有入口预计包括 `Preferences.swift`、`UsageStore.swift`、`AppDelegate.swift`、`SettingsWindowController.swift`、`UsageIcon.swift`，以及需要详情状态时的 `PanelController.swift`。若用系统 SQLite，补充 SwiftPM 的窄系统库声明，不引入第三方数据库框架。文档更新包括 README、DEVELOPMENT、必要的 AGENTS 架构说明及验证记录。

## 6. 验证矩阵与完成标准

| 类别 | 必须覆盖 |
| --- | --- |
| 数学口径 | 已知输出量/时长；区间重叠、相邻、乱序；工具间隔排除；推理 token 不重复 |
| 用量兼容 | 新旧 carrier、双载体重复、相同用量的不同响应、turn/thread 累计混淆、usage 迟到、缺失基线 |
| 增量文件 | 半行、UTF-8 跨块、超大行、有界尾读、截断/替换、归档、睡眠期间突增、权限错误 |
| 对话归属 | 切到空闲对话、新对话、子代理并行、CLI 同时运行、远端/云端不可达、多窗口歧义 |
