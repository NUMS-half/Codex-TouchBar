# Codex TouchBar v2.1.2

## 新功能

- 四个 Touch Bar 快捷操作槽位可分别选择功能和自定义短名称，保持固定尺寸与现有默认布局。
- 菜单栏面板与右键菜单新增“快捷操作…”入口，独立窗口支持预览、保存、取消和恢复默认。
- 增加“临时聊天”和“标记未读”。临时聊天调用 ChatGPT 原生菜单；标记未读在点击时读取当前快捷键配置，仅向前台 ChatGPT 执行。
- 支持将后退／前进组合放在任意槽位，允许重复选择同一功能。

## 显示与交互优化

- 详情面板底部四个按钮按刷新、Touch Bar 开关、登录启动开关、快捷操作排列，均分间距并对齐内容边缘；退出保留在右键菜单。
- 改善菜单栏“5H”“周”标签在浅色、暗色外观下的对比度。
- 功能候选仅保留 ChatGPT 专属菜单命令，按需刷新列表；配置保存不触发额度刷新，不新增后台轮询。

## 快捷键兼容

菜单功能直接执行原生菜单项，兼容修改或清除快捷键。“标记未读”支持含 Command、Control 或 Option 的单段组合键；清除、无效、冲突或不支持的绑定会提示不可用。

## 下载与校验

- `CodexTouchBar-v2.1.2-macos-arm64.zip`
- `CodexTouchBar-v2.1.2-macos-arm64.zip.sha256`

适用于 macOS 14 或更新版本、Apple Silicon（arm64）。应用采用 ad-hoc 签名，未经过 Apple 公证。

```bash
shasum -a 256 -c CodexTouchBar-v2.1.2-macos-arm64.zip.sha256
```
