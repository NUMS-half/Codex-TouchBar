# Codex TouchBar v2.2.0

这次更新集中改善额度记录、提醒与设置体验，保留原有Touch Bar布局和快捷操作。

## 额度曲线

- 新增独立曲线窗口，查看5H最近48小时、周额度最近14天的剩余额度变化。
- 历史保存在本机，跨退出与重启保留，超期自动清理。
- 实线连接连续记录，虚线连接采样空档或变化区段；悬停显示实测值，不补造历史数据。
- 支持清空历史并重新建立提醒基线，便于切换账户后重新记录。

## 可配置额度提醒

- 5H与周额度分别提供低额、恢复开关和1%～100%的阈值设置。
- 默认低于20%提醒，恢复达到100%并经后续查询确认后提醒。
- 持续处于同一状态不重复通知，去重状态跨重启保留；修改设置后从新查询建立基线。
- 提醒默认关闭，使用macOS系统通知，遵循专注模式，不播放自定义提示音。

## 统一设置与交互

- 设置整合为“通用”“额度提醒”“快捷操作”三个原生页签。
- 菜单面板底部统一为“额度曲线…｜设置…｜退出”，刷新移至标题旁。
- 刷新期间图标持续旋转，快速查询保留短暂反馈；使用同圆心的对称双箭头，旋转前后保持同色。
- 快捷操作草稿在切换页签时保留，保存后应用，关闭窗口丢弃未保存修改。
- README增加图文说明和快速上手步骤，开发说明独立整理。

## 签名与升级

- 构建改用持久证书签名，后续使用同一身份更新，避免辅助功能授权因程序哈希变化而失效。
- **从v2.1.x迁移时需要重新允许一次辅助功能**；若系统旧开关仍无效，请移除旧条目，再添加安装版CodexTouchBar。
- 本发布包采用固定自签名证书，**未经过Developer ID签名或Apple公证**；其他Mac可能提示开发者未经验证。请按系统提示处理，或选择从源码构建。
- 额度查询、菜单栏显示和历史记录不依赖辅助功能权限；该权限用于Touch Bar快捷操作。

## 下载与校验

适用于macOS 14或更高版本、Apple Silicon（arm64）：

- `CodexTouchBar-v2.2.0-macos-arm64.zip`
- `CodexTouchBar-v2.2.0-macos-arm64.zip.sha256`

```bash
shasum -a 256 -c CodexTouchBar-v2.2.0-macos-arm64.zip.sha256
```

历史数据从成功查询开始记录，旧版本没有可迁移的历史。工具不读取账户身份，换账户后建议清空历史。
