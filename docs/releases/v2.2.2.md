# Codex TouchBar v2.2.2

本次更新让额度图表在菜单面板内展开，采用更细致的圆角渐变柱状图，并补齐检查更新、关于与近期额度变化显示。

## 菜单与额度图表

- 点击“额度图表…”原位展开，左上角“返回”收回概览；支持中途反向切换和系统“减少动态效果”。修复面板尺寸回摆、重复动画和过渡内容裁切。
- 菜单箭头和正文沿用系统原生材质；额度卡片与绘图区采用相同的半透明略深底色，支持浅色和深色外观。
- 5H默认近6小时、每柱10分钟，可切换近12小时、每柱15分钟；周额度显示并保留近10天、每柱6小时。5H原始记录仍保留48小时。
- 柱高为时段末次查询的剩余额度，细线保留时段内观测范围；悬停查看实际时间、数值和记录条数。
- “回升”统一显示为“刷新”。采样空档使用淡色非实测柱连接；跨刷新或周期不明时沿用前值，在下次实测处跳变，不画缓慢上升，也不补造100%。估计只用于显示，不写入历史或参与提醒。

## 近期变化与提醒

- 5H独立统计近30分钟连续实测，显示“近…分钟观测下降…%”；周额度独立统计近24小时，显示“近…小时观测下降…%”，非整小时保留一位小数。
- 数据不足时按实际连续观测时长显示；5H不足15分钟、周不足1小时不显示。采样断档、刷新或口径变化会重建区段，旧数据不显示近期变化。
- 移除卡片上的一次性“恢复后提醒”及旧待处理请求，保留设置中的5H/周低额和恢复提醒。
- 新增可选的重置机会到期提醒，默认关闭；成功查询确认最近机会将在24小时内到期后提醒一次，跨重启去重，发送失败或取消后可重试。

## 常用软件功能

- 菜单栏右键新增“检查更新”“关于”“使用说明”和“反馈问题”。
- 更新检查仅由用户主动触发，读取本项目GitHub正式Release；支持版本比较、失败重试与发布页面入口，不自动下载或安装。
- 关于窗口显示应用版本、构建号、图标与项目入口。

## 升级说明

- 保留现有刷新设置、历史数据和Touch Bar快捷操作，周历史超过10天会自动清理。沿用固定签名身份。
- 额度查询仍使用本机app-server，不读取凭据或聊天内容；仅主动检查更新时访问公开GitHub发布信息。
- 发布包使用固定本机自签名证书，未经过Developer ID签名或Apple公证；其他Mac也可从源码建立自己的签名身份。
