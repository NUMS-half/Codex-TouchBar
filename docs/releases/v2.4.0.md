# Codex TouchBar v2.4.0

本次更新新增可选的当前对话 TPS 显示，并改善快捷操作设置和额度面板。

## 当前对话速度

- 在“设置 → 通用 → 会话速度”开启菜单栏 TPS。速度与 `tok/s` 显示在左侧，右侧为上下对齐的 H／W 剩余额度；菜单栏不再显示应用图标。
- 在有实体 Touch Bar 的 Mac 上，可在“设置 → 快捷操作”将任一位置设为“当前对话 TPS”。它占用一个快捷位置，仅显示速度，点击不执行操作；菜单栏和 Touch Bar 的显示独立配置。
- 数值是本轮模型平均输出速度，包含推理 token，排除工具执行与等待时间，通常在模型响应完成后更新。工具执行时保留最近测量；回答结束保留最终平均值，下一轮开始后重新等待。
- 只读取当前用户已有的本地会话信息，不增加模型请求，不读取登录凭据或保存聊天内容。可见对话通过窗口标题和本地索引匹配；系统限制标题读取时，可在设置中主动授权辅助功能。
- 同名对话、多个可见窗口、无法确认当前页面、远端或云端缺少本地记录时显示 `—`，不猜测或沿用其他对话的速度。Codex 内部 IPC 和日志格式变化可能使该功能暂时不可用，额度功能仍可使用。

## 界面和修复

- 快捷操作页面现在显示待保存、已保存和已撤销状态；“撤销更改”恢复已保存值，无修改时保存和撤销按钮不可用。
- 收紧额度卡片中数字与进度条的间距，保留原有字体、颜色和原生弹出面板材质。
- 修复普通刷新可能清除可用重置机会最近到期时间的问题。每次已允许的额度查询都会一并读取明细，不增加刷新次数；没有有效日期时不推测。
- 修复缓存对话往返、回答结束、短暂失联、日志不可读、连接恢复与重复记录等 TPS 边界，减少重复解析和时间区间计算。

## 升级与验证范围

- 保留已有额度设置、提醒、缓存和历史；TPS 默认关闭。无 Touch Bar 的 Apple Silicon Mac 可使用菜单栏 TPS。
- 本工具不读取账号身份，同套餐不同账号的历史自动隔离仍未实现；换账号后可在图表页清空历史并重新建立提醒基线。
- 构建与合成自检覆盖 TPS 计算、对话切换、设置、额度和提醒；原生面板检查包含浅／深色与箭头。当前 Command Line Tools 环境只确认 XCTest 目标编译，未将其报告为已执行。
- 当前账户的只读探测和本机安装曾验证 TPS 与重置到期数据；有／无实体 Touch Bar 的两类 Apple Silicon Mac、各档账号及多窗口／远端场景的完整实机验收仍待补齐。
- 发布包沿用固定本机自签名证书，未经过 Developer ID 签名或 Apple 公证；其他 Mac 也可从源码建立自己的签名身份。

## 下载与校验

适用于 macOS 14 或更高版本、Apple Silicon（arm64），不支持 Intel：

- `CodexTouchBar-v2.4.0-macos-arm64.zip`
- `CodexTouchBar-v2.4.0-macos-arm64.zip.sha256`

下载两个文件至同一目录后运行：

```bash
shasum -a 256 -c CodexTouchBar-v2.4.0-macos-arm64.zip.sha256
```
