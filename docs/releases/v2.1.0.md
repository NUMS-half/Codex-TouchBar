# Codex TouchBar v2.1.0

本次更新将 Touch Bar 改为半幅额度显示，并加入与 ChatGPT 桌面版原生菜单联动的前台操作。

## 更新内容

- 左半区显示 5 小时与每周剩余额度；右半区提供“新对话”“侧边栏”“设置”和共用一个按钮宽度的后退、前进箭头。
- 点击任一额度卡可展开查看完整重置时间，并通过独立按钮返回或刷新。
- 缩短额度卡、统一元素间距，并标记额度缺失或缓存过期状态。
- 操作按钮仅在点击时通过 macOS 辅助功能触发 ChatGPT 原生菜单项，不依赖默认快捷键；用户修改或清除快捷键后仍可使用。
- 移除不稳定的输入聚焦与语音听写按钮，以及侧边栏状态轮询。

## 安装

下载 `CodexTouchBar-v2.1.0-macos-arm64.zip`，解压后先退出旧版，再将 `CodexTouchBar.app` 放入“应用程序”目录。首次使用操作按钮时，请按系统提示授予辅助功能权限。首次打开如被 macOS 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。

同时下载 `.sha256` 文件，可使用以下命令核对压缩包：

```bash
shasum -a 256 -c CodexTouchBar-v2.1.0-macos-arm64.zip.sha256
```

## 已知限制

- 仅支持 Apple Silicon（arm64）与 macOS 14+；Touch Bar 视图需要实体 Touch Bar。
- Touch Bar 展示依赖未公开的 macOS 接口，接口失效时会退回紧凑摘要模式。
- ChatGPT 更新若改变原生菜单结构或菜单标题，操作按钮可能提示暂不可用；不会向其他应用发送按键。
- 发布包为 ad-hoc 签名，未经过 Apple 公证。
