# Codex TouchBar v2.0.2

本次修复 ChatGPT 桌面应用更新后，Codex TouchBar 无法刷新额度的问题。

## 修复内容

- 优先使用新版 ChatGPT 应用内置的原生 Codex CLI，避免退回依赖 Node.js 的 Homebrew 启动脚本并报 `status=127`。
- 自检现在会确认新版内置 CLI 的选择顺序。

## 安装

下载 `CodexTouchBar-v2.0.2-macos-arm64.zip`，解压后先退出旧版，再将 `CodexTouchBar.app` 放入“应用程序”目录。首次打开如被 macOS 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。

同时下载 `.sha256` 文件，可使用以下命令核对压缩包：

```bash
shasum -a 256 -c CodexTouchBar-v2.0.2-macos-arm64.zip.sha256
```

## 已知限制

- 仅支持 Apple Silicon（arm64）与 macOS 14+；Touch Bar 视图需要实体 Touch Bar。
- Touch Bar 展示依赖未公开的 macOS 接口，接口失效时会退回紧凑摘要模式。
- 发布包为 ad-hoc 签名，未经过 Apple 公证。
