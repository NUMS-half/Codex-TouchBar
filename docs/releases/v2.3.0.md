# Codex TouchBar v2.3.0

本次更新支持无 Touch Bar 的 Apple Silicon Mac，并让额度显示跟随服务端实际返回，适应套餐改名和额度窗口的增减。

## 无 Touch Bar 的 Mac

- 菜单栏、额度图表、刷新和提醒继续可用；设置自动隐藏 Touch Bar 显示开关、专属刷新选项和快捷操作页。
- 检测暂时失败或系统接口不可用时，设置会说明当前使用菜单栏。启动、唤醒和打开设置时重新检测，不新增轮询。
- 已保存的 Touch Bar 开关和按钮配置保留；能力恢复后继续使用原配置。有实体 Touch Bar 时沿用现有两卡、四按钮及右侧系统 Control Strip 布局。
- 仅使用菜单栏额度监控无需辅助功能权限；本次未将四个 Touch Bar 快捷操作移植到其他入口。

## 套餐与额度显示

- 只按实际返回的 300／10080 分钟识别 5H／每周窗口，不维护套餐与额度规则对照表。窗口取消后清除旧值，重新返回后自动恢复显示。
- 尚未读取、缺失窗口或未知重置次数显示 `—`；缺失不解释为无限额、0% 或 100%。其他时长暂不展示。查询失败仍保留旧额度并标记过期。
- Free、Go、Plus 使用规范名称；已知 Pro 类型及旧式 x5／x20 名称统一显示 Pro，悬停查看原始名称。未知新名称保留原文，长名称在现有标签内截断。
- 重置次数与到期信息每次采用新快照，不因次数相同沿用旧到期时间。面板打开期间的既有刷新会读取明细，不增加额度请求或定时器。
- 窗口消失后清理对应提醒基线，重新出现的首次观测不误发低额或恢复提醒。重置机会到期提醒仅在明确有可用次数且到期时间有效时判断。

## 升级与验证范围

- 保留现有设置、缓存和历史；无需数据库迁移。仅适配基础 Codex 的 5H／每周额度，不覆盖全部 ChatGPT 功能额度。
- 本工具不读取账号身份，同套餐不同账号的历史自动隔离仍未实现；换账号后可在图表页清空历史并重新建立提醒基线。
- 合成协议样本和隔离自检覆盖套餐名称、窗口增减、未知重置明细、硬件能力、设置页面及提醒管线。当前 Command Line Tools 环境未实际执行 XCTest 用例，不能将测试目标构建成功等同于 XCTest 通过。
- 各档真实账号登录，以及有／无 Touch Bar 的两类 Apple Silicon Mac 的完整真机验收仍待补齐；这些边界不以离线样本替代。
- 沿用固定本机自签名证书，未经过 Developer ID 签名或 Apple 公证。其他 Mac 也可从源码建立自己的签名身份。

## 下载与校验

适用于 macOS 14 或更高版本、Apple Silicon（arm64），不支持 Intel：

- `CodexTouchBar-v2.3.0-macos-arm64.zip`
- `CodexTouchBar-v2.3.0-macos-arm64.zip.sha256`

下载两个文件至同一目录后运行：

```bash
shasum -a 256 -c CodexTouchBar-v2.3.0-macos-arm64.zip.sha256
```
