# Codex TouchBar v2.2.1

本次更新让额度刷新更可控，改善曲线阅读体验，并修复Touch Bar展开视图和后台刷新调度问题。

## 自定义额度刷新

在“设置 → 通用 → 额度刷新”中，独立管理七种触发：

- 启动工具、打开菜单栏面板、ChatGPT切到前台、电脑睡眠唤醒。
- 前台定时、后台定时，以及Touch Bar展开视图的刷新按钮。
- 前台、后台间隔均可选择30秒、1分钟、2分钟、5分钟或10分钟。

默认保持原有行为，旧的前台间隔自动保留。修改立即保存，不额外查询；关闭菜单栏面板不再刷新。菜单栏刷新图标和右键“刷新”始终可用。关闭自动刷新后，历史与提醒仍随其他已开启的触发和手动查询更新。

## 界面与修复

- 曲线窗口采用紧凑余额摘要、独立图表区域、简短图例和右侧清空按钮，支持浅色／暗色与窗口缩放。
- 密集额度回升标记自动合并并显示次数，避免文字重叠；悬停仍可查看实测记录。
- Touch Bar展开视图为系统Control Strip预留空间，修复刷新按钮被截断；两张额度卡保持等宽、间距一致。
- 修复在多个后台App之间频繁切换导致自动刷新一直延后的问题。
- 为服务响应及异常数值增加边界保护，保留刷新失败时继续显示最近成功额度的行为。
