# Codex TouchBar v2.1.1

本次更新修复额度卡展开和关闭按钮的问题，并改善 Touch Bar 的按钮比例与间距。

## 更新内容

- 修复点击额度卡无反应的问题；展开后保持文字在上、进度条在下，并可返回或独立刷新。
- 左侧始终显示单个关闭按钮，解决首次启动出现重复叉号的问题；点击后菜单中的 Touch Bar 状态同步变为“关”。
- 后退和前进合并为带中间分割线的一个按钮，左右分别可点击；整组与“新对话”“侧边栏”“设置”等宽，避免最右侧箭头被截断。
- 统一额度卡和按钮的间距，优化右侧留白；增大三个文字按钮的字号，并提高关闭图标不透明度。
- 菜单按钮使用“Touch Bar：开/关”和“登录启动：开/关”格式。

## 安装

下载 `CodexTouchBar-v2.1.1-macos-arm64.zip`，解压后先退出旧版，再将 `CodexTouchBar.app` 放入“应用程序”目录。首次使用操作按钮时，请按系统提示授予辅助功能权限。首次打开如被 macOS 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。

同时下载 `.sha256` 文件，可使用以下命令核对压缩包：

```bash
shasum -a 256 -c CodexTouchBar-v2.1.1-macos-arm64.zip.sha256
```

## 已知限制

- 仅支持 Apple Silicon（arm64）与 macOS 14+；Touch Bar 视图需要实体 Touch Bar。
- Touch Bar 展示依赖未公开的 macOS 接口，接口失效时会退回紧凑摘要模式。
- ChatGPT 更新若改变原生菜单结构或菜单标题，操作按钮可能提示暂不可用。
- 发布包为 ad-hoc 签名，未经过 Apple 公证。
