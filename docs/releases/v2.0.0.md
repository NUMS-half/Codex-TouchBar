# Codex TouchBar v2.0.0

首个公开版本，适用于 macOS 14 或更高版本、带实体 Touch Bar 的 Apple Silicon MacBook Pro。

## 包含内容

- 菜单栏中的 5 小时与每周 Codex 剩余额度。
- Codex Desktop 前台时显示的双卡 Touch Bar 视图，同时保留右侧系统 Control Strip。
- 手动与定时刷新、失效缓存、登录启动和私有接口回退。
- 额度与进度条统一的红、橙、黄、绿四色状态。

## 安装

下载 `CodexTouchBar-v2.0.0-macos-arm64.zip` 后解压，将 `CodexTouchBar.app` 拖入“应用程序”目录。首次打开如被 macOS 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。

同时下载 `.sha256` 文件，用以下命令核对完整性：

```bash
shasum -a 256 CodexTouchBar-v2.0.0-macos-arm64.zip
```

## 已知限制

- 仅支持 Apple Silicon（arm64）与 macOS 14+。
- Touch Bar 功能依赖未公开的 macOS 接口；系统变更可能导致自动退回紧凑摘要模式。
- 发布包为 ad-hoc 签名，未经过 Apple 公证。
