# Codex TouchBar v2.0.1

本次更新改善菜单栏详情面板的布局和异常状态显示，并重新设计应用图标。

## 更新内容

- 面板更加紧凑；“积分”和“可用重置”改用与系统一致的线性图标。
- 显示可用重置机会中最近一个的到期时间（服务端提供时）。
- 网络异常时保留旧额度，以简短提示标记过期状态；点击“查看详情”可阅读并复制完整错误。
- 修复标题中重复显示“更新于”的问题。
- 换用更简约的双额度触控栏图标。

## 安装

下载 `CodexTouchBar-v2.0.1-macos-arm64.zip`，解压后将 `CodexTouchBar.app` 放入“应用程序”目录。如果已安装旧版，先退出旧版再替换。首次打开如被 macOS 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。

同时下载 `.sha256` 文件，可使用以下命令核对压缩包：

```bash
shasum -a 256 -c CodexTouchBar-v2.0.1-macos-arm64.zip.sha256
```

## 已知限制

- 仅支持 Apple Silicon（arm64）与 macOS 14+；Touch Bar 视图需要实体 Touch Bar。
- Touch Bar 展示依赖未公开的 macOS 接口，接口失效时会退回紧凑摘要模式。
- 发布包为 ad-hoc 签名，未经过 Apple 公证。
