# 额度面板与高优先级提醒改进

## 范围

- 详情卡统一剩余口径，主显示重置倒计时，完整时间可悬停查看，新鲜度移到面板底部。
- 从现有本地历史汇总近期连续观测；不读取会话或凭据，不外推可用时长。
- 以现有恢复阈值设置一次性提醒，支持取消与持久化；目标可在长期提醒关闭时独立编辑。
- 默认关闭的重置机会到期提醒：已确认最近机会在24小时内到期时提醒一次。

## 审查及修正

按项目 code-review-and-quality 技能做独立只读审查和修正后复核。

1. 分钟合并可能覆盖小幅回升。现在将连续性断点保存在现有历史的 discontinuity 字段，分钟内取最大值；汇总使用数据库最终观测携带的断点。没有将图表“大幅回升”标记误用为全部连续性判据。
2. 提醒生成不等于发送成功。新提醒在系统通知服务接受提交、且取消与配置代次检查通过后才确认完成。失败和取消保留请求供后续新鲜成功查询重试；请求 ID 防止旧投递完成时删除新的订阅。
3. 卡片固定等宽铺满内容区，并覆盖正常、低额、旧数据、无窗口和等待恢复五种状态的浅/深外观。
4. SQLite 的 Date 往返精度不用于精确比较重置时间；小于一秒的差异视为相同。

复核结论：此前两项 Required 已修正，未发现新的高确信阻塞问题。可选建议（固定同分钟测试时间、独立编辑恢复目标）也已采纳。
