# 额度历史图表 UI 优化

后续菜单栏集成与空档插值调整见 [菜单面板导航优化](2026-10-15-menu-panel-navigation.md)，下文保留本次初版图表记录。

## 设计与行为

借鉴 Agent HUD 的紧凑图表与 Token Monitor 的渐变、分组和悬停层级，保留原生 AppKit 和本项目的四档剩余额度色。重点放在图表本身，窗口背景、标题、网格和控件保持克制。

- 默认渐变柱状图，5H每柱30分钟、周额度每柱4小时；柱高是时段内末次查询的剩余百分比，绝不累计百分比。
- 柱色沿用红/橙/黄/绿四档，纵向由浅至深渐变；细线展示该时段留存记录的最低/最高余额。
- 没有记录的时段留空；实际0%绘制底线标记，避免与空记录混淆。
- 悬停显示实际查询时间、剩余、记录范围和条数；不将按分钟合并后的记录条数称为查询次数。
- 可切换趋势曲线，只有连续段带淡渐变填充；空档和变化区段继续用虚线连接，回升标记保留原来的合并与布局规则。
- 聚合结果缓存随数据、时间范围或额度窗口变化失效，悬停不重新分桶。切换样式只重绘本地记录，不发起额度查询。

视觉沿用现有画布（浅色 `#F5F6F8`、深色 `#202126`）、图表表面（`#FFFFFF` / `#292B31`）和蓝色曲线（`#237AD1` / `#67AAF4`）；原生系统字体保留，余额摘要、轴和辅助文字层级一致。渐变仅用于数据标记与连续曲线面积。

## 验证

- 分桶自测：末次值而非求和/平均、无序输入、窗口和时间筛选、时段内高低、空桶、真实零、最右边界。
- 离屏 UI：两种图表样式，760×520与620×420，浅/深外观，周窗口，空记录、单点、密集回升及悬停。
- 命中检查：左端部分时段、零值柱、空桶不会借用远处记录、恰好在右端边界的读数可悬停。
- 20160条历史记录的绘制由自测实际执行，聚合缓存覆盖周视图；运行耗时仅作本次环境诊断，不是正式性能基准。
- 反转分桶时间范围条件后实际自测失败，恢复源码再构建，确认检查能发现此回归。
- 独立只读审查提出的 Required（记录条数不能称为查询次数）已修复，最终复核通过。
- 已通过项目安装流程更新本机应用；安装版实际自测、监控 UI 自测与设置自测均通过，固定证书验证通过，安装版与构建版可执行文件 SHA-256 一致。

自动 UI 检查使用隔离设置、临时历史和假通知，不发送真实通知。`swift test`在当前命令行环境仅确认测试目标编译，实际运行验证以上述自测为准。

## 文件

`UsageChartBuckets.swift`负责分桶语义；`UsageChartView.swift`负责渐变、细线、曲线和悬停绘制；`UsageMonitoringWindows.swift`负责窗口与样式切换。诊断继续位于独立文件，历史存储和额度请求协议未因本轮视觉优化变化。
